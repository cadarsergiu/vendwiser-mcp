# Security policy

Please report security problems in the Vendwiser service privately by email to **[hello@vendwiser.ai](mailto:hello@vendwiser.ai)** with the subject `Security`. Do not open a public issue, and do not include real customer data, passwords or tokens in your report.

This repository contains only documentation and configuration files; the server is a hosted service. How Vendwiser protects your accounts and data is described in [docs/security.md](docs/security.md).
